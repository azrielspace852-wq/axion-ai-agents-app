Features

Features

AXION AI v2.8.3 is a browser-based AI agent. Structured state is persisted in IndexedDB; file bytes use OPFS when available, with an IndexedDB fallback. Requests still go to the selected AI provider and AXION Search when those features are used.

Multi-provider chat

Connect OpenAI, Anthropic, Google, Groq, xAI, and custom OpenAI-compatible endpoints. Add custom providers without a fixed provider-count limit and configure each provider on its own settings page.

AXION Search

AXION Search is the sole integrated search provider through the official JavaScript SDK. Search runs as a background agent tool; URL-only results trigger independent page-content extraction fallbacks when accessible.

Live execution steps

Search, page fetch, tools, and generation status are shown in a collapsible “Step by step” section. Status updates are emitted while work is running.

Private file workspace

An internal-only terminal creates, reads, edits, moves, and deletes files and folders; it supports navigation and ZIP creation/extraction. Generated files remain in File Library until explicitly shared or delivered.

File Library

Upload, preview, download, extract, share, and delete files. ZIP uploads are unpacked locally while preserving relative paths. Duplicate uploads are detected and attachments can be selected from the Library or the device.

Canvas

Use the /canvas command to show long text or code in a dedicated inline Canvas. The preview begins with exactly 15 lines, with Copy and View All controls.

Revisions and attachments

Edit loads the user message back into the composer, including its attachments. User and assistant messages show revision navigation and a current/total counter where revisions exist.

Memory and tasks

Conversation summaries and persistent task metadata are stored in IndexedDB. Memory summaries can be inspected from Settings → Personalization → Memory Summary.

Token controls

Configure a Max Token context budget and output-token cap. Token estimates are character-based approximations unless a provider tokenizer is available. Auto-Continue is off by default.

Backup and restore

Export settings, API-related local state, conversations, tasks, memory, preferences, and File Library blobs into one ZIP. Restore from a compatible AXION backup ZIP.

Personalization and UI

Settings are grouped by category. Theme changes apply immediately and persist. The interface supports English and Bahasa Indonesia, custom instructions, and a first-message welcome dismissal.

Git and knowledge tools

GitHub/GitLab/Gitea integration uses configured credentials and permission levels. An optional knowledge repository can be synchronized and searched as context.

Storage and network notes

IndexedDB stores structured state and metadata; OPFS stores file contents when the browser supports it. File bytes may fall back to IndexedDB Blob storage. Chat content is sent to the chosen AI provider. Search queries go to AXION Search, and URL-content fallback may use the configured public extraction endpoints described in Privacy.
