Quick Start Guide

Get AXION AI running in under a minute.

1. Add an API key

Open Settings, find your provider (OpenAI, Anthropic, Google, Groq, xAI Grok, or a custom OpenAI-compatible endpoint), and paste your API key. Save. The key is stored locally by this app, but is transmitted to the matching provider when authenticated requests are made.

2. Pick a provider & model

In the Chat topbar, select a provider. The model dropdown filters to that provider's models and, if a key is present, auto-fetches the latest live list. You can also add a custom model ID in Settings.

3. Chat

Type a message and press Send (or Enter on desktop). On mobile, Enter inserts a newline — use the Send button or Ctrl+Enter. Use the + attachment button to choose files from File Library or your device. ZIP archives are extracted locally with their folder paths preserved.

4. Watch the agent work

When the AI needs tools (AXION Search, page extraction, internal file operations, git, device context, or knowledge base), actions appear in the collapsible “Step by step” section with progress updates.

Gestures: long-press any message for Copy all / Select text; swipe from the left screen edge to open the sidebar; tap 👻 in the chat top bar for a temporary chat that is never saved.

5. File Library and generated files

Files uploaded by you and files created privately by AXION appear in File Library. The internal terminal creates individual files and folders before packaging projects as ZIP archives. Files remain private until explicitly shared or sent in chat. In Library you can preview, download, extract ZIP files, share, or delete files.

6. Canvas and revisions

Enter /canvas followed by a newline and content to create an inline Canvas preview (15 lines initially, with Copy and View All). Edit a user message to load its text and saved attachments into the composer. Use the revision controls under messages to switch among available versions.

7. Enable device context (optional)

In Settings, toggle GPS permission so the AI knows your location. Time, date, timezone, weekday, and screen size are always available on-device and are injected into the AI's context automatically.

8. Sync the knowledge base (optional)

In Settings → Git, click Sync knowledge repo to download and index azrielspace852-wq/knowladge. The AI can then search and read those files as extra knowledge.

9. Connect your git (optional)

Add your GitHub/GitLab/Gitea username and Personal Access Token. Choose a permission level:

  • Low — AI can only read repositories (safest).
  • Medium — AI asks your confirmation before every write/create action.
  • High — AI acts autonomously. Not recommended — high risk.

10. Token budget and backup

Settings → Personalization has Max Token and Auto-Continue (OFF by default). Token counts are estimates where no exact tokenizer is available. Settings → Data exports or restores a ZIP backup of settings, conversations, memory, tasks, and File Library files. Backups may contain API keys and private data.

Keyboard shortcuts

  • Enter — send (desktop) / newline (mobile)
  • Shift+Enter — newline, always
  • Ctrl/Cmd+Enter — send, always
