Privacy

AXION AI stores application data locally where possible, but it is not offline-only. Features that use an AI provider, AXION Search, Git hosting, or page-content fallbacks make network requests to those services. This page identifies the principal data flows.

Stored on this device

  • Structured application state: settings, conversation history, API provider configuration, memory summaries, task metadata, and File Library metadata are stored in IndexedDB. A small localStorage compatibility cache remains for older synchronous code paths.
  • Files and binary data: OPFS is used when available; file data falls back to Blob records in IndexedDB when OPFS is unavailable.
  • Memory and tasks: locally generated conversation summaries and task lists persist in IndexedDB.

Use Settings → Data to export a full backup ZIP or restore a previous AXION backup. Clearing browser/site data may remove local content; export a backup first if you need to keep it.

Data sent to external services

  • AI messages: messages, selected context, and any attachment content needed for an answer are sent from the browser to the AI provider you selected. The provider's own terms and privacy policy apply.
  • Web search: search queries are sent to AXION Search at the configured service URL (default https://axion-search.axn.cc.cd). AXION Search is the app's sole integrated search provider.
  • Page extraction fallback: if search returns only URLs, the app may request page content from Jina Reader and/or public CORS extraction services as fallback. Those services can receive the page URL and network request metadata; page access may fail or be limited.
  • Git and knowledge sync: repository requests go to the configured GitHub/GitLab/Gitea or other git host. A configured knowledge repository may be downloaded from its hosting service.
  • GPS: location access is permission-gated. If location context is included in a prompt, it is sent to the selected AI provider with that request.

File privacy

Files uploaded to the File Library and files created in the internal workspace stay in local browser storage until used in a chat, explicitly shared, or otherwise sent by a user-requested action. Attaching a file to a message and sending that message shares its content with the selected AI provider. The local app does not provide server-side encryption for local database entries.

Security notes

  • API keys are stored locally in browser-managed storage and are not encrypted by this app. Use scoped keys and do not use a shared/untrusted device.
  • Browser storage can be removed by clearing site data, private browsing policies, quota pressure, or browser-specific behavior. Keep backups for important files.
  • Git write permissions are controlled by the configured permission level. Review confirmation prompts and use the least privilege needed.
  • Network requests to AI, search, Git, and extraction providers are governed by each service's policies; AXION AI cannot guarantee their retention or handling practices.
