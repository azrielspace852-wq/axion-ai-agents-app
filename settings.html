Settings

Structured settings and conversations are stored in IndexedDB; file bytes are stored in OPFS when available. Data remains on this device except requests sent to the providers you configure.

Appearance & Language

On mobile phones the enter/newline key inserts a newline by default; send with the button or Ctrl+Enter.

API Keys & Providers

Configure each provider on its dedicated page. Custom OpenAI-compatible providers can be added without a fixed provider limit.

AXION Search

AXION Search is the only search provider. It runs as an agent tool in the background and cannot be disabled in Settings. If a result contains only a URL, independent page-content fallbacks are attempted.

Default: https://axion-search.axn.cc.cd
